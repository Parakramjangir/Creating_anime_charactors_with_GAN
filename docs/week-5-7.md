# Week 5-7: Conditional GAN for Anime Face Generation

## Objective

The objective of Week 5-7 was to extend the anime face generation pipeline from an unconditional DCGAN to a Conditional DCGAN. The goal was to generate anime faces using both random noise and label information.

## Work Done

In the earlier weeks, Vanilla GAN and DCGAN models were trained on the Anime Face Dataset. These models generated anime faces only from random noise and did not provide control over the generated output.

For Week 5-7, a labelled version of the Anime Face Dataset was prepared. Since the original dataset did not contain class labels, pseudo-labels were created using visual clustering. These labels were then used as conditioning information for training a Conditional DCGAN.

The main steps were:

* Created `labels.csv` for the anime face dataset
* Assigned pseudo-labels to images using clustering
* Loaded image-label pairs using a custom PyTorch Dataset
* Implemented a Conditional Generator and Conditional Discriminator
* Trained the Conditional DCGAN on anime face images
* Saved generated samples at different epochs
* Plotted generator and discriminator loss curves
* Compared results with previous GAN models

## Dataset Preparation

The Anime Face Dataset was used as the base dataset. Since it contains only images and no predefined labels, pseudo-labels were generated by grouping visually similar images into different classes.

The final labelled dataset followed this format:

```text
image_path,label
images/img_001.jpg,class_0
images/img_002.jpg,class_2
images/img_003.jpg,class_1
```

These labels were encoded into numerical class indices before being passed to the model.

## Model Architecture

A Conditional DCGAN was implemented using PyTorch.

The generator takes:

* random noise vector
* label embedding

The discriminator takes:

* image
* label information

This allows the model to learn conditional image generation, where the output depends on both the noise vector and the selected label.

## Training

The model was trained on 64x64 anime face images. Binary Cross Entropy loss was used for both the generator and discriminator. Generated samples were saved at different epochs to observe training progress.

The training outputs included:

* epoch-wise generated samples
* final generated sample grid
* generator and discriminator loss curve

## Results

The Conditional DCGAN successfully completed the training pipeline and generated anime face samples using label-conditioned inputs.

The generated images showed the model’s ability to learn anime-like facial structures, although some outputs were still blurry or contained artifacts. This is expected because GAN training is unstable, and the labels used were pseudo-labels rather than manually verified semantic labels.

Compared to the earlier DCGAN, the Conditional DCGAN added label-based control, but the image quality was not always better because the task became more difficult.

## Comparison with Previous Models

| Model             | Dataset                     | Conditioning | Output Type                  | Observation                                         |
| ----------------- | --------------------------- | ------------ | ---------------------------- | --------------------------------------------------- |
| Vanilla GAN       | Anime Face Dataset          | No           | Anime faces                  | Basic generated samples with limited clarity        |
| DCGAN             | Anime Face Dataset          | No           | Anime faces                  | Improved visual quality due to convolutional layers |
| Conditional GAN   | Labelled/simple dataset     | Yes          | Label-controlled images      | Introduced conditional generation                   |
| Conditional DCGAN | Labelled Anime Face Dataset | Yes          | Label-controlled anime faces | Final model with conditional generation             |

## Limitations

The main limitations were:

* The original dataset did not contain real labels
* Pseudo-labels may not perfectly represent meaningful visual categories
* GAN training is unstable and sensitive to hyperparameters
* Some generated images remained blurry
* Longer training or better labels could improve results

## Outcome

By the end of Week 5-7, the project successfully moved from unconditional anime face generation to conditional anime face generation. The final model demonstrated how label information can be added to a GAN pipeline to control the generation process.
